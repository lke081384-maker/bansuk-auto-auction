# 반석자동차경매 홈페이지

대표가 네이버 블로그(blog.naver.com/heechul5)에 올린 글을 2026-11-24에 확인해 만든 소개 홈페이지입니다.

## 고치는 방법

페이지 파일(`index.html` 등)은 직접 고치지 않습니다. `build.py` 안의 내용을 고친 뒤 다시 실행합니다.

```
python build.py
```

- 전화, 주소, 카카오톡 주소: `build.py` 맨 위의 값
- 절차, 약속, 낙찰 사례, 후기, 자주 묻는 질문: `build.py`의 `STEPS`, `PROMISES`, `CASES`, `REVIEWS`, `FAQS`
- 모양: `assets/style.css`

## 주소를 바꿀 때

도메인을 새로 연결하면 `build.py`의 `BASE` 한 줄만 바꾸고 다시 실행합니다. canonical, sitemap, robots, llms.txt, 구조화 데이터가 함께 바뀝니다.

`robots.txt`는 도메인 맨 위에 있을 때만 검색 로봇이 읽습니다. `github.io/저장소이름/` 주소에서는 읽히지 않으므로, 자체 도메인을 연결한 뒤에 효력이 생깁니다.

## 아직 확인하지 않은 것

- 사업자등록번호, 매매업 등록 정보 (꼬리말에 넣지 않았습니다)
- 수수료 금액 (블로그에 표가 없어 "카카오톡으로 요청"으로만 안내합니다)
- 요일별 경매장 일정 (2020년에 쓰고 이후 고친 블로그 글 기준입니다)
